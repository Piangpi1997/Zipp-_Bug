# Zip_Bug Studio — Antigravity Android Studio

Zip_Bug is being designed as a **real Android development/runtime studio**, not a fake demo shell.

## Core product
- BYO AI Providers: OpenAI, Gemini, Claude, user-owned API keys.
- App Creator: project scaffolding for Kotlin, Java, JavaScript, JSON, HTML/CSS.
- LIKEFIGMA Studio: visual UI/UX editor with a portable screen schema.
- AI Zipper: package mini-apps as `app.json + www/`.
- Local Runtime: sandboxed localhost engine on `127.0.0.1:3131`.
- Termux Engine: Gradle/Java/Python/ffmpeg/yt-dlp/git/aapt2/zipalign.
- APK Builder: real build status, real logs, real artifacts.
- Social Recap Lab: authorized media/link workflow for transcript, recap, dialogue, subtitle and dub pipelines.

## Non-negotiable rules
- No fake install.
- No fake bug/fake success.
- No fake certification.
- No pretend build result.
- API keys never belong in source control.
- Imported ZIPs never receive unrestricted shell access.
